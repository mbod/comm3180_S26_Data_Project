## Diversity in Higher Ed: What does it say about new affirmative action policies?

# Overview

In this project, we aim to investigate some questions about the influence of diversity on higher education on various levels. We will use the following datasets:
1. The [College Scorecard](https://collegescorecard.ed.gov/) data from the U.S. Department of Education.
2. The U.S. [Census Data](https://data.census.gov/table).
3. Athletic scholarships and student athlete data.

From this project, we want to understand how the demographic characteristics of schools affect student's earning potential after they graduate. Along the same lines, we want to answer whether this demographic characteristics are affected by the diversity of the surrounding community.

The Github repository contains the following files
- `data`
    - This folder contains all the files of our data, including the racial composition dataframes obtained from our analysis.
- `data_analysis`
    - This folder contains JupyterHub notebooks were analysis was conducted. The ReadMe on the folder shows more detailed information on each notebook.
- `data_story_outputs`
    - This folder contains our long form blogpost presenting our findings.
- `presentations`
    - This folder contains the slideshows presented in class. The ReadMe on the folder shows more detailed information. 
- `project_plan.ipynb`
    - This notebook shows our early project plan.
- `qs_and_hypotheses.ipynb`
    - This notebook shows our research questions and hypotheses.
